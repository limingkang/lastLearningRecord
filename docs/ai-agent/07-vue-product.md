# Vue 前端和 AI 产品化

你的优势在前端，所以不要只做命令行 Demo。AI Agent 求职项目一定要有可交互界面，让面试官能直接看见产品能力。

## 学习目标

- 能用 Vue 做 AI 聊天界面
- 能实现流式输出体验
- 能做文件上传和知识库管理
- 能展示 Agent 执行过程
- 能设计可演示的 AI 产品

## 聊天界面

基础能力：

- 输入框
- 消息列表
- loading 状态
- 流式输出
- 重新生成
- 停止生成
- 复制回答
- 历史会话

注意：AI 产品不是简单 textarea 加按钮，交互细节会明显影响作品质量。

## 流式输出

需要掌握：

- EventSource
- fetch stream
- AbortController
- Markdown 渲染
- 代码块高亮
- 自动滚动
- 输出中断恢复

## 文件上传

RAG 项目需要完整上传体验。

功能包括：

- 拖拽上传
- 上传进度
- 文件类型校验
- 文件列表
- 索引状态
- 删除文档
- 重新索引

## 引用来源展示

知识库回答必须展示引用来源。

可以展示：

- 文件名
- 页码
- 标题
- 命中的文本片段
- 相似度分数
- 点击展开原文

## Agent 执行过程展示

Agent 项目需要让用户看见执行步骤。

可以展示：

- 当前步骤
- 已调用工具
- 工具参数
- 工具结果摘要
- 等待人工确认
- 最终报告

## 产品化细节

需要补齐：

- 空状态
- 错误状态
- 权限提示
- 任务进度
- 操作确认
- 移动端适配
- 深色模式可选

## 推荐实践

为前面的 RAG 和 Agent 项目做一个统一 Vue 前端：

- 左侧会话列表
- 中间聊天窗口
- 右侧知识库或工具调用记录
- 支持文件上传
- 支持流式回答
- 支持引用来源展开

## 面试要能回答

- Vue 如何处理流式输出
- 如何中断正在生成的回答
- 如何展示 RAG 引用来源
- Agent 执行过程如何可视化
- AI 产品有哪些特殊交互状态
- 为什么 AI 应用不能只做普通表单
